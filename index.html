Camera do estudio: arraste com esquerdo para orbitar, direito ou Shift + esquerdo para deslocar, roda para aproximar/afastar, duplo clique ou Home para recentrar. WASD move no plano, Q/E desce-sobe, R/F aproxima-afasta pelo teclado, Shift acelera. Posicao usa unidades do modelo; rotacao usa graus. Selecione Alvo + Gizmo para arrastar no 3D. Pause a simulacao, ajuste braco/antebraco/mao e grave keyframes para criar o movimento.

Hitboxes
